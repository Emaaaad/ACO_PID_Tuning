# Ant Colony Optimization (ACO)-Based PID Controller Tuning

This repository contains the MATLAB implementation and result figures for my Bachelor thesis project at Qazvin Azad University, supervised by [Prof. Hamid Qadiri](https://scholar.google.com/citations?user=NFe6cnoAAAAJ&hl=en).

All related explanations for this project are now maintained on my personal website, including the system model, delay modeling, PID objective, ACO workflow, figures, interpretation, and run instructions:

[Read the full Bachelor thesis explanation](https://emaaaad.github.io/#bachelor-thesis)

## Repository Contents

- MATLAB code for ACO-based PID controller tuning
- Result figures for the delayed baseline response, optimized PID response, and ITAE convergence

## Running the Code

Open the MATLAB script in MATLAB with the Control System Toolbox available, then run the script. It reports the optimized PID gains and minimum ITAE value, and generates the project figures.
